# อโยธยา Idle

เกมเว็บแนว idle: ไพร่คนหนึ่งเวียนว่ายตายเกิด 7 ชาติตลอดอายุกรุงศรีอยุธยา (พ.ศ. 1887–2310)
ฉบับรื้อใหม่จาก prototype v0.19 — แบบเกมอยู่ในเอกสารออกแบบ (Claude Docs: "อโยธยา Idle — เอกสารออกแบบเกม (ฉบับรื้อใหม่)")

**สถานะ:** ขั้น 3 ตัวเกม (logic) + บอททดสอบเสร็จ ยังไม่มีหน้าจอเกม — หน้าเว็บตอนนี้เป็นคลังเนื้อหา · ขั้นถัดไป: ชิ้นทดลองชาติ 1 อายุ 9–20

## โครงสร้าง

| ที่ | มีอะไร |
| --- | --- |
| `data/*.json` | เนื้อหาเกมทั้งหมด (ต้นฉบับจริง) |
| `content.xlsx` | สำเนาเนื้อหาสำหรับแก้ใน Excel |
| `src/content/` | ชนิดข้อมูล + ตัวโหลดเนื้อหา |
| `src/engine/core.ts` | ตัวเกม: เวลา/ปิดแอป, แนวทางชีวิต, อาชีพ, เงิน/บุญ/ความชอบ, เหตุการณ์, ฉากจบ |
| `src/engine/balance.ts` | ค่าสมดุลทั้งหมด (แก้ที่นี่ที่เดียว) |
| `tools/sim.ts` | บอทเล่น 54 รอบ (6 อาชีพ × 3 แนวทาง × 3 seed) เทียบเป้าหมาย |
| `tools/test-engine.ts` | ทดสอบกติกาพื้นฐาน (ปิดแอป, เซฟ/โหลด, ไม่ทะลุเพดาน) |
| `tools/validate.ts` | ตรวจข้อมูล (รันอัตโนมัติก่อน build) |
| `tools/xlsx-*.ts` | แปลง JSON ⇄ Excel |
| `tools/legacy/` | สคริปต์ที่ใช้ดึงเนื้อหาจาก v0.19 (ใช้ครั้งเดียว) |
| `docs/content-notes.md` | จุดในเนื้อหาที่ควรตรวจ/แก้ |

## แก้เนื้อหาผ่าน Excel

1. เปิด `content.xlsx` แก้ แล้วบันทึก
2. `npm run xlsx:import` → เขียนกลับเป็น `data/*.json` และตรวจข้อมูลให้
3. ถ้าแก้ JSON ตรงๆ แล้วอยากได้ Excel ใหม่: `npm run xlsx:export`

ผลของตัวเลือกเขียนแบบ `บารมี+2, โภคทรัพย์-1`

## คำสั่ง

```
npm install
npm run dev        # เปิดดูในเครื่อง
npm run validate   # ตรวจข้อมูล
npm test           # ทดสอบกติกาตัวเกม
npm run sim        # บอทเล่นทดสอบสมดุล (--detail ดูรายชาติ)
npm run build      # ตรวจ + build (GitHub Actions ทำให้เองทุกครั้งที่ push)
```
