# แนวทาง: สัตว์เลี้ยง และตัวละครผู้หญิง

## สัตว์เลี้ยง (ตกลงแล้ว — ทำต่อจากความสำราญ)
- เลี้ยงได้ทีละตัว ได้จากตลาดหรือกงกรรม (เช่น ลูกหมาหลงมาหน้าบ้าน) · ตั้งชื่อได้
- ค่าของสัตว์: ความอิ่ม (ลดตามเวลา) · ความผูกพัน (เล่น/ให้อาหาร/ฝึก → บัฟแรงขึ้น) · อายุ
- อายุสัตว์ในเกม ≈ 2–3 เท่าของอายุจริง (หมา/แมว ~12–15 ปีจริง → ~30–40 ปีในเกม) · มี 3 ช่วงวัย เด็ก/โต/แก่ ท่าทางต่างกัน
- สัตว์ที่ตายไปแล้วไปอยู่ใน "สวนสวรรค์สัตว์เลี้ยง" (ชื่อชั่วคราว — ตั้งชื่อตามยุคอีกที เช่น ทุ่งดอกบัวสวรรค์) ดูย้อนหลังได้
- ระหว่างรอ: แตะสัตว์ในฉาก = เล่น · ปุ่มให้อาหาร · ฝึก = มินิเกมแตะจังหวะ (แบบยมโลก)
- เริ่ม 3 ชนิด × 1 สายพันธุ์ แล้วค่อยเพิ่ม (เก็บลงสมุดสะสม)
  - หมา: บางแก้ว (เฝ้าบ้าน → หลบหลีก) · หลังอาน (ล่าสัตว์ → พละกำลัง ต่อสู้) · หางดาบ (ไหวพริบ)
  - แมว (ตำราแมวมงคลสมัยอยุธยา): วิเชียรมาศ (บารมี ความชอบ) · สีสวาด (เงิน) · ขาวมณี (บุญ ไสยเวทย์) · ศุภลักษณ์ (ทรัพย์) · โกญจา (กันภัย)
  - นก: นกเขา (สำราญ) · นกกรงหัวจุก (สำราญ ไหวพริบ) · นกเอี้ยง (ความรู้)
- ภาพ: ต่อสายพันธุ์ 3 ช่วงวัย × (ยืน/เดิน/นั่งหรือนอน/ดีใจ) — ทำทีละสายพันธุ์

## ตัวละครผู้หญิง (แนวทางไว้ก่อน — ยังไม่ทำ)
เป็นเรื่องใหญ่เพราะบริบทสังคมอยุธยาต่างจากผู้ชายมาก จึงไม่ควรแค่เปลี่ยนรูป
- **เลือกเพศตอนเกิดแต่ละชาติ** (วิญญาณเดียวกันเกิดเป็นหญิงหรือชายก็ได้ — เข้ากับธีมเวียนว่ายตายเกิด) · บุญ/ความเก่งข้ามชาติยังพกไปได้
- **อาชีพของผู้หญิง** — บางสายเหมือนกัน บางสายเปลี่ยนชื่อ/บริบท บางสายเฉพาะ:
  - พ่อค้า → แม่ค้า/แม่ค้าสำเภา (ผู้หญิงอยุธยาคุมการค้าในตลาดจริง — สายที่เด่นมาก)
  - เกษตรกร → เหมือนเดิม (ทำนา ทอผ้า เลี้ยงไหม)
  - บริหาร → สายฝ่ายใน: นางข้าหลวง → ท้าวนาง → ท้าวศรีสัจจา (คุมกิจการในวัง)
  - ปุโรหิต → แม่หมอ/หมอตำแย/ผู้ทำพิธี · สายบรรพชิต → แม่ชี
  - สายลับ → นางข้าหลวงสอดแนมในวัง/แม่ค้าสืบข่าว
  - ทหาร → กองอาสาหญิง/นักรบหญิงยามศึก (มีตำนาน เช่น สมเด็จพระศรีสุริโยทัย) — ทางที่ยากและหายาก
- **กงกรรมและเหตุการณ์** ต้องมีชุดของผู้หญิง (การแต่งงาน การเรือน การค้า ข้อจำกัดทางสังคม) และปรับข้อความเหตุการณ์ประวัติศาสตร์ที่ใช้คำว่า "นาย"
- **ภาพ** ต้องทำชุดใหม่ทั้งหมด (เด็กหญิง ลูกมือ ผู้ใหญ่ ชรา ตามอาชีพ)
- **ลำดับที่แนะนำ:** ทำหลังระบบชาย 7 ชาติครบและเนื้อหาเสถียร · เริ่มจากโครงข้อมูลให้รองรับ "เพศ" ในตัวละคร + ชื่อยศสองชุด
