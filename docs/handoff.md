# อโยธยา Idle — สรุปส่งต่อสำหรับแชทใหม่ (ถึง v0.16.0)

**วิธีใช้:** เปิดแชทใหม่ในโปรเจกต์ Ayothaya แล้วพิมพ์ว่า "อ่าน claude/handoff.md แล้วทำต่อ"

## ผู้พัฒนาและวิธีทำงาน
- Earth คุยภาษาไทย ชอบคุยแนวทางก่อนลงมือ
  - เสนอเป็นข้อๆ ให้เลือก แล้วรอคำตอบเป็นเลขข้อ หรือคำว่า "ทำเลย"
- repo: `ppaocharoen/ayothaya-idle` (GitHub Pages)
  - เล่นได้ที่ https://ppaocharoen.github.io/ayothaya-idle
  - ต่อท้ายลิงก์ด้วย `?dev` จะเร่งเวลา ×3000 และเปิดแผง dev
- ทุก commit ต้องลงท้ายด้วย attribution footer ตาม system reminder ของแชทนั้น
- ภาพดิบอยู่ในเครื่อง Earth ที่ `G:\คอมพิวเตอร์เครื่องอื่นๆ\My Laptop\Ayothaya\art\raw`
  - ดึงผ่านการเชื่อมคอมพิวเตอร์ ด้วย `device_stage_files`

## สถาปัตยกรรม
- Vite + TypeScript ไม่ใช้เฟรมเวิร์ก
- `src/engine/` คือเครื่องยนต์เกม ไม่แตะ DOM
  - `core.ts` ตรรกะหลัก
  - `balance.ts` ตัวเลขสมดุลทั้งหมด
  - `pets.ts` สัตว์เลี้ยง
  - `afterlife.ts` ยมโลก
  - `rng.ts` สุ่มแบบมี seed
- `src/game/` คือ UI
  - `main.ts` ร้าน แท็บ แผง dev และการ์ด
  - `scene.ts` ฉาก canvas 240×168 วาดตัวละครและสัตว์
  - `minigames.ts` มินิเกม
  - `changelog.ts` เลขเวอร์ชันและรายการเปลี่ยนแปลง
- `data/*.json` คือเนื้อหาเกม: อาชีพ กงกรรม เหตุการณ์ประวัติศาสตร์ ร้าน ฉากจบ ฯลฯ
  - แก้ผ่าน Excel ได้ด้วย `npm run xlsx:export` และ `npm run xlsx:import`
  - ตรวจข้อมูลด้วย `npm run validate`
- ภาพที่ใช้ในเกมอยู่ที่ `public/art/`
- สคริปต์ตัดภาพอยู่ที่ `tools/art/`
  - `snap_sheet.py in.jpg cols rows px py out [bbox]` ส่วนใหญ่ใช้ pitch ประมาณ 6.625
  - `clean_grid.py` ลบเส้นตาราง
  - ฉากหลังย่อเหลือกว้าง 480 ด้วย BOX filter แล้วตัดพื้นเขียว

## ก่อน deploy ต้องผ่าน
1. `npx tsc --noEmit`
2. `npm test`
3. `npm run sim -- --strict`
4. `npx tsx tools/sim.ts --notasks --strict` (กรณีผู้เล่นไม่เล่นมินิเกม)

**สำคัญ:** ข้อ 3 และ 4 ต้องผ่านทั้งคู่

- CI เรียง test → sim → build แล้วค่อย deploy
- เช็กผล deploy ได้จาก GitHub actions runs API
- **ระวัง:** อย่าใช้ `pkill -f` หรือ `pgrep -f` กับข้อความที่อยู่ในคำสั่งเดียวกัน เพราะจะไปฆ่า shell ตัวเอง
- **ระวัง:** แก้ข้อความไทยที่มี `/` ด้วย Python ห้ามใช้ sed

## ระบบหลักที่มีแล้ว (ย่อ)
- **ชีวิตและชาติ:** เกิดใหม่หลายชาติ มี 7 รัชสมัย (`reincarnateMerit` 8500)
- **อาชีพ:** 6 อาชีพ ได้แก่ บริหาร ทหาร พ่อค้า เกษตรกร ปุโรหิต สายลับ
  - ยศ Lv.0–19 มีทางแยกสว่าง/มืดที่ Lv.2
  - `workTier` แบ่งชั้นยศเริ่มที่ Lv 0, 6, 12 และ 17
- **กงกรรมและเหตุการณ์:** กงกรรมทั่วไป (สันทนาการ สุขภาพ อบายมุข) กงกรรมวัยรุ่น และงานราชการ 96 เหตุการณ์ (`work.json`)
  - เหตุการณ์ประวัติศาสตร์มีภาพ H ได้แก่ L1-H02, L2-H04, L4-H09
  - เพิ่ม id ภาพ H ใหม่ที่ `HIST_ART` ใน `main.ts`
- **ตอนปิดเกม:** เวลาเดิน ×0.1 สูงสุด 2 ปีในเกม เก็บกงกรรมค้างได้ 12 เรื่อง
- **รหัสเซฟ:** รูปแบบ AY2z บีบอัด คัดลอกหรือวางได้ และ export/import เป็นไฟล์ได้
- **ฉาก:** ภาพตามวัยและอาชีพ
  - เด็ก A, ลูกมือ B, วัยรุ่น T/TP, ผู้ใหญ่ C/U/UP, ชรา D/V/VP
  - ยศสูงทางสว่าง C8/D8 ทางมืด C9/D9
  - ฉากในบ้าน `bg_in0–5`, `bg_inP` และที่ทำงาน `bg_work1–6`
- **ยมโลก:** พญายม ศาล นรก แม่น้ำ เปรต วิมาน
- **สัตว์เลี้ยง:** 8 สายพันธุ์ เลี้ยงได้ทีละตัว
  - ให้อาหาร แตะเล่น ฝึกได้ทุก 7 วัน
  - ตายแล้วไปสวนสวรรค์สัตว์เลี้ยง
- **ราชกิจค้าง:** งานงอก 1 ชิ้นทุก 20–30 วัน สะสมได้สูงสุด 6 ชิ้น
  - กองเต็มเกิน 20 วัน นายจะไม่พอใจ
  - เปิดเฉพาะงานที่อยู่ใน `taskReady`
  - รายละเอียดอยู่ใน `claude/minigames.md`
- **บริวาร (v0.15.0):** 6 ประเภท ซื้อได้ไม่จำกัด ราคา +15% ต่อคน
  - จำนวนคิดแบบเพดานอ่อน `n/(1+n/5)`
  - แต่ละประเภทให้ผล income / help / joy / lawyer / guard ต่างกัน
  - ตอนปรับสมดุลบริวาร `siegeBase` ถูกลดเป็น 0.19
- **แผง dev:** ข้ามเวลา ตั้งอาชีพ/ยศ/ทาง/บ้าน/บริวาร เรียกเหตุการณ์ ดูยมโลก ลองมินิเกม (เกมย่อยเรียกเป็น `งาน:เกมย่อย`) และเสกสัตว์

## งานค้าง (เรียงตามที่คุยไว้)
1. **มินิเกมอีก 4 อาชีพ** แต่ละอาชีพมีทางสว่าง/มืด ตามแผนใน `claude/minigames.md`
   - พ่อค้า: ชั่งของ / ต่อรองราคา (ทางมืดถ่วงตาชั่ง)
   - เกษตรกร: เกี่ยวข้าว / ไล่นก (ทางมืดซ่อนข้าวหลวง)
   - ปุโรหิต: ลำดับพิธี / หาฤกษ์ (ทางมืดลัดพิธี)
   - สายลับ: สะกดรอย / หาไส้ศึก (ทางมืดขายข่าว)
   - Earth ถามว่าจะทำอาชีพไหนต่อ แต่ยังไม่ได้ตอบ
   - ขั้นตอนเพิ่มงาน: เขียนเกมใน `TASK_GAMES` → เพิ่มชื่องานใน `taskReady` → รัน sim ทั้งสองแบบ
2. **ภาพ H ที่รอ Earth เจน:** H-L4-H11 (ประกาศอิสรภาพ) และ H-L7-H14 (เสียกรุงครั้งที่ 2) ได้ภาพแล้วต้องเพิ่มใน `HIST_ART`
3. **F5 วิญญาณ:** ตอนนี้ใช้รูปเด็กย้อมสีฟ้าแทน ได้ภาพแล้วต้องเขียนโค้ดเพิ่ม
4. **ค่าเลี้ยงดูบริวาร:** ตกลงว่ายังไม่ทำตอนนี้
   - ถ้าทำภายหลัง ให้เป็นเบี้ยหวัดหักอัตโนมัติปีละครั้ง
   - เงินไม่พอ ความภักดีลด แล้วบารมีลดเล็กน้อย
5. **พักไว้:** อุปกรณ์แบบ paper-doll (จุดยึดของถือและหมวก, ผ้าเปลี่ยนสีด้วย palette แบบ Ragnarok) · เพลงสายสมร (รอโน้ต) · ตัวละครผู้หญิง (มีแค่แผนใน `claude/design-pets-and-female.md`)
6. **แยกโปรเจกต์:** เกมเลี้ยงสัตว์เป็นโปรเจกต์แยก มีไฟล์สรุป `pet-game-brief.md` และ `pet-game-starter.zip` แล้ว
